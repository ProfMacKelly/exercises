How to edit, save, and publish
  1. Select a page on the left and edit its fields. Use Add page to create another decision or outcome.
  2. Add answer choices and choose their destinations from the dropdowns. Select the exercise’s starting page below.
  3. Click Refresh preview to try the student version, including every branch.
  4. Click Save project to download an editable backup. Later, use Open project to keep editing it.
  5. Click Export student HTML. Upload that single file to GitHub. Use a separate filename for each exercise, or rename it index.html to replace the main exercise.

Edits are saved as a draft in this browser when browser storage is available. They do not change the published website. Download project backups before changing browsers or clearing browser data.
